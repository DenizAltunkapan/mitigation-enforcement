# Security policy

This repository is an educational, local systems-security testbed. Its C
examples are intentionally vulnerable to demonstrate memory-corruption behavior
under controlled build settings. They are not production code. Do not use this
project to attack systems without authorization.

If you find a vulnerability in the capture scripts, VM launchers, validation
tooling or other repository infrastructure, please report it privately through
[GitHub's vulnerability reporting page](https://github.com/DenizAltunkapan/exploit-evolution/security/advisories/new).
Include the affected component, impact and reproduction steps. Please avoid
posting a working infrastructure exploit in a public issue before the maintainer
has had a chance to review it.

The maintainer should enable private vulnerability reporting before public
release so external reporters can use that link.

The deliberately unsafe behavior documented in each lab is expected behavior,
not a security report for this repository.
